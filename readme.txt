1. Устновить node.js ссылке https://nodejs.org/en/download
2. Попробовать выполнить команду node -v в терминате, если не сработало — перезапустить vs code или перезагрузить комп
3. В VSCode открыть папку с проектом
4. Перенести все файлы, кроме index.html в папку public. 
5. index.html перенести в корневую папку проекта
6. В терминале выполнить 2 команды
	- npm i
	- node index
Если выполнение скриптов блокируется, открываем Power Shell и выполняем команду 
Пробуем повторить 
8. Открыть сайт на localhost:{ваш_порт} через браузер
